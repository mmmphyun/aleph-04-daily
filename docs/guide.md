### 제출할 과제:
T04 · 오늘의 진짜 정보판 — 데이터가 안 올 때

공개 결과물 URL과 소스 저장소 URL이 모두 필수이며 확인 파일은 선택입니다.

결과물 URL (필수)
`https://`
제출하는 모든 URL은 계정 생성·로그인·인증·초대·비밀번호·OAuth·CAPTCHA 없이 새 시크릿 창에서 열려야 합니다.
소스 저장소 URL (필수)
`https://github.com/owner/repo/commit/전체-commit-hash`
브랜치나 저장소 첫 화면이 아니라, 전체 소스 상태를 다시 받을 수 있는 40자리 또는 64자리 소문자 full commit이 포함된 HTTPS 고정 URL을 적습니다.
재현·통과 확인 4가지 (권장)
```
어디로 가나요: 공개 결과물 URL
무엇을 하나요(3단계 이내): 1) … 2) … 3) …
무엇이 보이면 통과: …
안 될 때: …
```

네 항목은 후행 채점의 평가 기준입니다. 이 형식을 모두 따르지 않아도 제출 자체와 강사·마스터 승인 흐름은 막지 않습니다. 다만 비워 두면 후행 채점에서 이 평가 항목이 기록 없음으로 반영됩니다.
```
AI와 내 판단 3줄 (권장)
AI에게 맡긴 일: …
내가 판단한 일: …
AI 말을 안 들은 일: … (없으면 그 이유)
```

세 줄은 후행 채점의 평가 기준입니다. 형식 미준수로 제출·승인을 차단하지는 않습니다. 다만 비워 두면 후행 채점에서 이 평가 항목이 기록 없음으로 반영됩니다.
```
선택된 파일 없음
확인할 파일 선택
과제 결과를 확인할 파일을 선택하세요
낼 수 있는 형식: PDF · DOCX · XLSX · PPTX · TXT · MD · CSV · JSON · HTML · HTM · CSS · JS · MJS · PNG · JPG · JPEG · WEBP · ZIP
```

선택한 파일을 비공개로 업로드합니다.
학생은 자기 파일만, 담당 강사와 운영자는 확인 대상 학생의 파일만 볼 수 있습니다. 한 번에 10개·합계 8MB까지 올릴 수 있습니다.

과제 제출은 시간과 장소에 관계없이 언제든 할 수 있습니다. 강의장 실습 시간은 프리미엄 연결에만 적용됩니다.

지금 제출할 수 없는 이유: 결과 주소, 소스 주소 또는 제출 파일 중 하나를 넣어 주세요.
